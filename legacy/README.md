# Legacy — retired NixOS base

This directory holds the **v1 NixOS base** (`nixos/`, `flake.nix`, `flake.lock`),
retired on 2026-11-17 when Enclave moved to an **Arch** base. See
`../docs/superpowers/specs/2026-11-17-enclave-os-v2-arch-windowslike-design.md`
(§0) for why.

Kept for reference and history only — nothing here is built. The live project is
the Arch `archiso` profile under `../arch/`.
